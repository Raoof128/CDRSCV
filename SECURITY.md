# Security Policy

## Supported versions

The `main` branch receives security fixes. Please update to the latest released
package before reporting issues.

## Reporting a vulnerability

1. Email security@cdrscv.example.com with the following information:
   * Description of the vulnerability and its potential impact
   * Steps to reproduce or proof-of-concept code
   * Any relevant logs, stack traces, or mitigations attempted
2. Expect an acknowledgment within five business days.
3. Please do not open public GitHub issues for security reports until a fix is
   released.

## Coordinated disclosure

We follow responsible disclosure. After a fix is available we will publish
release notes summarising the impact and crediting reporters who wish to be
named.
